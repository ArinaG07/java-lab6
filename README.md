# Лабораторная работа № 6. Рефлексия, аннотации и работа с файловой системой

**ФИО автора:** Гуляева Арина Евгеньевна 

**Группа:** ФИТ-251

## Описание
Приложение демонстрирует создание собственной аннотации `@Repeat`, вызов методов через Reflection API (включая приватные и защищенные) и работу с файловой системой через `java.nio.file` (создание, копирование, обход и удаление файлов и директорий).

## Команды для сборки и запуска
1. Сборка проекта:
   `mvn clean package` (или `mvnw.cmd clean package`)
2. Запуск приложения:
   `java -jar target/java-lab6-1.0-SNAPSHOT.jar`
